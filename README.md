# StreamHelper

Локальная панель с таймкодами, отдельной очередью вопросов и одним итогом для выбранной трансляции. В итоге видны замеченные зрители и модераторы, категории и названия эфира, длительность и платежи DonationAlerts за этот эфир.

## Запуск из EXE

Запустите `StreamHelper.exe` на Windows x64. Панель откроется в браузере по адресу `http://127.0.0.1:18768/`. Оставьте окно сервера открытым. Чтобы остановить сервер, закройте окно или нажмите Ctrl+C. Python и WebSocket-библиотека уже в сборке.

EXE хранит базу и настройки в `%LOCALAPPDATA%\StreamHelper`. Чтобы перенести историю из версии с исходниками, остановите обе версии и скопируйте `data\streamhelper.sqlite` в этот каталог. Подключение DonationAlerts можно настроить заново. Для EXE адрес возврата — `http://127.0.0.1:18768/donationalerts/callback`, актуальный адрес также указан в инструкции внутри панели.

Чтобы пересобрать EXE:

```powershell
py -3 -m pip install pyinstaller websocket-client
.\build-exe.ps1 -Python (py -3 -c "import sys; print(sys.executable)")
```

Сборка сохраняется в `dist\StreamHelper.exe`.

## Запуск из исходников

В PowerShell из папки проекта запустите `.\launch.cmd` и откройте [панель](http://127.0.0.1:18767/). Нужен Python 3.10+ и пакет `websocket-client`. Для установки в локальную папку проекта:

```powershell
py -3 -m pip install --target data/twitch-runtime -r requirements-twitch.txt
.\launch.cmd
```

Если запускаете через Python из комплекта Codex, выполните ту же команду с этим интерпретатором вместо `py -3`. Лаунчер ищет библиотеку в `data/twitch-runtime`.

## Streamer.bot

1. В Streamer.bot подключите аккаунт владельца канала Twitch.
2. Включите локальный **WebSocket Server** в **Servers/Clients → WebSocket Server**. При адресе `127.0.0.1`, порте `8080` и пути `/` панель подключится автоматически. Если параметры отличаются, задайте `STREAMERBOT_WS`. Если включён пароль, задайте `STREAMERBOT_PASSWORD` перед запуском. [Настройка WebSocket](https://docs.streamer.bot/api/websocket/guide/configuration)
3. Запустите панель до начала эфира. Streamer.bot передаст события старта и остановки. Если эфир уже идёт и событие старта пропущено, можно начать сессию вручную. В этом случае её временные границы определяются вручную.
4. Зрители пишут `!вопрос текст` в обычном чате Twitch. Вопросы появляются в разделе **«Вопросы к стримеру»**. Таймкод можно поставить в любой активной сессии.

Темы берутся из категорий и названий, присланных Streamer.bot. Список зрителей включает авторов сообщений и зрителей, обнаруженных Streamer.bot во время сессии. Модератор попадает в итог по признаку роли, значку или действию модерации. Twitch не предоставляет поимённый список всех фактических зрителей. Подключение использует учётную запись в Streamer.bot. Собственный Client ID Twitch не требуется. [События Streamer.bot](https://docs.streamer.bot/api/websocket/guide/events)

## DonationAlerts

Откройте [инструкцию подключения](http://127.0.0.1:18767/help). Зарегистрируйте приложение в DonationAlerts с адресом возврата `http://127.0.0.1:18767/donationalerts/callback`. В панели откройте карточку **DonationAlerts**, введите Client ID и Client Secret и сохраните настройки. Нажмите **«Подключить DonationAlerts»** и подтвердите доступ к истории донатов. Секрет и токены хранятся локально в каталоге `data`. [Регистрация и API DonationAlerts](https://www.donationalerts.com/apidoc)

Панель загрузит платежи автоматически при завершении сессии. Кнопка **«Обновить донаты»** повторно загружает историю, в том числе для прошедшего эфира. Фильтр использует время создания платежа и границы выбранной сессии. Для дат из API без часового пояса принят UTC. Если история вашего аккаунта отдаёт такие даты в другом часовом поясе, перед запуском задайте смещение в минутах через `DA_UTC_OFFSET_MINUTES`, например `180` для UTC+3. Суммы отображаются в исходных валютах.

## Выгрузка итога

Выберите сессию. Во вкладке панели можно скачать JSON или текст UTF-8 для титров, а также скопировать URL интеграции. GET `/api/sessions/{id}/summary` возвращает актуальные данные итога. GET `/api/sessions/{id}/summary?download=1` скачивает JSON. GET `/api/sessions/{id}/credits` скачивает текст. API доступен только на этом компьютере. Временные отметки — Unix-время в секундах, поле `duration` — длительность в секундах.
