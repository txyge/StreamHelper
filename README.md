# СтримПомощник

Локальная панель для начинающего Twitch-стримера. Начните эфир, отмечайте моменты, обрабатывайте вопросы и сохраняйте клипы из записи. По завершении выберите, какие итоги показать зрителям. Для показа используются встроенный тестовый чат и 55-секундный демонстрационный ролик.

## Зависимости и запуск на Windows

- Python 3.10+ со стандартной библиотекой и SQLite. Устанавливать Python-пакеты для запуска приложения не требуется.
- FFmpeg и FFprobe из одной сборки с кодировщиком `libx264`. Добавьте папку с обоими файлами в `PATH` или задайте переменные с полными путями.
- Edge, Chrome или другой браузер с поддержкой входного видео. Для демонстрации используется MP4/H.264. OBS нужен только для включения карточки в сцену.

Откройте PowerShell в папке `StreamHelper`. При доступных командах `py` (или `python`), `ffmpeg` и `ffprobe` запустите:

```powershell
.\launch.cmd
```

На компьютере, где выполнялась работа, можно использовать Python из комплекта Codex и установленные вместе с Overwolf FFmpeg и FFprobe. Команды для этой машины:

```powershell
$env:STREAMHELPER_PYTHON = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
$env:STREAMHELPER_FFMPEG = Get-ChildItem (Join-Path $env:LOCALAPPDATA 'Overwolf/Extensions') -Filter ffmpeg.exe -File -Recurse |
    Where-Object { Test-Path (Join-Path $_.DirectoryName 'ffprobe.exe') } |
    Select-Object -First 1 -ExpandProperty FullName
$env:STREAMHELPER_FFPROBE = Join-Path (Split-Path $env:STREAMHELPER_FFMPEG) 'ffprobe.exe'
.\launch.cmd
```

| Адрес | Назначение |
|---|---|
| [http://127.0.0.1:18765/](http://127.0.0.1:18765/) | Панель стримера |
| [http://127.0.0.1:18765/viewer](http://127.0.0.1:18765/viewer) | Карточка зрителей и адрес для OBS Browser Source |

Оставьте окно сервера открытым. Остановка через `Ctrl+C`. По умолчанию данные записываются в папку `data`. Для новой демонстрации с чистой базой задайте новый каталог, например `.\launch.cmd --data data/demo-run --port 18766`, и используйте порт 18766 в обоих адресах. Сервер слушает только `127.0.0.1`.

## Показ за 3–5 минут

1. Откройте экран зрителей во второй вкладке. В панели начните эфир «Первый забег». Через несколько секунд отметьте момент «Победа на арене», добавьте приватную заметку.
2. В антиспойлере сохраните игру «Лабиринт» и фразу `тайный финал`. В тестовом чате отправьте от разных ников «Привет!», `!вопрос Когда следующий эфир?`, `ТАЙНЫЙ ФИНАЛ` и `!вопрос Где тайный финал?`. Покажите очередь проверки, восстановите последний вопрос и отметьте первый отвеченным.
3. Нажмите «Загрузить деморолик». Введите `45` в поле позиции, нажмите «Перейти» и «Сохранить последние 30 секунд». Откройте первый клип через «Смотреть» или «Скачать». В списке появится интервал 00:15–00:45 независимо от времени работы эфира.
4. Завершите эфир. Покажите длительность, отметку, клип, статусы вопросов и счётчик скрытых сообщений. Выберите момент и первый вопрос, введите результат челленджа и анонс, сравните предпросмотр с пустой второй вкладкой.
5. Нажмите «Показать зрителям». Вторая вкладка обновится автоматически. Измените результат в черновике и сравните с опубликованной карточкой. При необходимости остановите сервер, запустите его той же командой и снова откройте обе страницы.

Голос включается на одну команду по кнопке. Доступность зависит от браузера, микрофона и сервиса распознавания. Основной сценарий использует кнопку сохранения и работает без Twitch. Тестовые сообщения обрабатываются локально.

## Устройство и проверка

`app.py` принимает HTTP-запросы. `streams.py` и `schema.sql` управляют сессиями и SQLite. `chat.py` обрабатывает вопросы и спойлеры. `media.py` проверяет запись и экспортирует клипы. `publication.py` сохраняет копию выбранных полей. Интерфейс находится в `web/`, демонстрационный файл создан генератором `testsrc2` FFmpeg.
