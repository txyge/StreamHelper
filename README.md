# СтримПомощник

Локальная панель для прямого эфира Twitch. После подключения сервис автоматически создаёт сессию по трансляции, отсчитывает таймкоды от времени старта Twitch, читает вопросы из чата и собирает карточку итогов. Для демонстрации без аккаунта Twitch доступен отдельный локальный режим.

## Запуск Windows

Из этой папки:

```powershell
.\launch.cmd
```

[Панель стримера](http://127.0.0.1:18767/) · [Экран зрителей / OBS Browser Source](http://127.0.0.1:18767/viewer).

Нужен Python 3.10+. Если системного Python нет, лаунчер может использовать локальный комплект Python от Codex. Чтобы указать другой интерпретатор, задайте `STREAMHELPER_PYTHON`. Сервер хранит данные в `data` и слушает только `127.0.0.1`.

## Подключить реальную трансляцию

1. Установите зависимость в тот Python, который запускает панель. При системном Python:

   ```powershell
   py -3 -m pip install -r requirements-twitch.txt
   ```

   Для Python из комплекта Codex:

   ```powershell
   $env:STREAMHELPER_PYTHON = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
   & $env:STREAMHELPER_PYTHON -m pip install --target data/twitch-runtime -r requirements-twitch.txt
   .\launch.cmd
   ```

2. Зарегистрируйте приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps) с типом клиента **Public**. Если при регистрации нужно указать OAuth Redirect URL, используйте `http://localhost:18767`. Вход по коду устройства завершится на сайте Twitch.
3. В панели введите **Client ID**, нажмите **«Подключить Twitch»**, откройте ссылку подтверждения и авторизуйтесь под аккаунтом владельца канала. Код устройства отображается рядом со ссылкой. Секрет приложения и ключ трансляции для этой схемы не нужны. Авторизация сохраняется на этом компьютере в `data/twitch-auth.json`. Храните этот файл локально.
4. Запустите трансляцию как обычно. Если идёт демонстрационный эфир, завершите его. Панель увидит реальную трансляцию и откроет сессию. Зрители пишут `!вопрос ...` в обычном чате Twitch. Вопросы появятся в очереди панели, где их можно отметить отвеченными.
5. Выберите текущий прямой эфир, задайте длительность от 5 до 60 секунд и нажмите **«Создать клип на Twitch»**. Twitch выбирает фрагмент около момента запроса. Для клавиши нажмите **«Назначить клавишу»**, затем букву или цифру. Клавиша запоминается и действует, пока вкладка в фокусе и курсор вне поля ввода. Готовая ссылка появится после обработки. При переходе с предыдущей версии подтвердите разрешение `clips:edit`.
6. Завершите трансляцию. Проверьте собранную карточку и нажмите **«Показать зрителям»**. Уже открытая вкладка зрителей обновится без перезагрузки. Позже можно опубликовать обновлённый снимок, например если Twitch подготовил клип после завершения эфира.

### Что попадает в карточку

| Раздел | Источник |
|---|---|
| Название, категории и длительность | Twitch Helix и события начала/конца эфира. Смена категории фиксируется по опросам API. |
| Участники чата | Объединение снимков списка чата и авторов сообщений за время подключения в этой сессии. Twitch не предоставляет имена всех фактических зрителей. |
| Самые активные | До десяти авторов по числу полученных сообщений. |
| Топ поддержки эфира | До десяти участников по полученным в сессии Twitch Bits. |
| Поддержка за день | До 100 позиций из официального рейтинга Bits за день Twitch, с датой дня в карточке. |
| Модераторы | Назначенные модераторы канала из Twitch Helix. |
| Клипы | Готовые клипы, созданные из панели, и найденные клипы, которые Twitch связывает с VOD этого эфира. Проверка свежих итогов продолжается примерно 15 минут после окончания. |

Статистика чата и Bits за эфир формируется с момента подключения приложения, включая текущий эфир, если вы подключились после его начала. Денежные донаты через DonationAlerts, Streamlabs и другие сервисы пока требуют отдельной интеграции. Антиспойлер и автомодерация отложены.

## Демонстрация без Twitch

Демонстрационная сессия позволяет посмотреть панель и проверить отметки. Для создания клипа требуется прямой эфир Twitch.
