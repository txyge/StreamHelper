DonationAlerts

  1. Войдите в DonationAlerts под аккаунтом, который принимает донаты. Зарегистрируйте приложение в разделе Application Registration официальной документации.
  2. В настройках приложения укажите адрес возврата http://127.0.0.1:18767/donationalerts/callback.
  3. Скопируйте Client ID и Client Secret. В карточке DonationAlerts заполните оба поля и нажмите Сохранить настройки.
  4. Нажмите Подключить DonationAlerts и подтвердите доступ к истории донатов на сайте DonationAlerts. Выберите эфир и нажмите Обновить донаты. При завершении эфира данные также загружаются автоматически.

Streamer.bot

  1. В Streamer.bot откройте Platforms → Twitch → Accounts. В разделе Broadcaster Account нажмите Login и войдите в аккаунт стримера.
  2. В Servers/Clients → WebSocket Server укажите адрес 127.0.0.1, порт 8080 и путь /. Нажмите Start.
  3. На том же компьютере откройте панель. При этих настройках она подключится автоматически. Если в вашем WebSocket включён пароль, задайте STREAMERBOT_PASSWORD перед запуском панели. Для другого адреса доступна переменная STREAMERBOT_WS.
  4. Проверьте статус Streamer.bot подключён. Во время активной сессии отправьте !вопрос Как дела? в чат Twitch и проверьте очередь вопросов.

Как забрать итог

Выберите сессию в панели. В блоке Выгрузка итога скачайте JSON для своего приложения или текст UTF-8 для титров. Текстовый файл можно открыть в редакторе и использовать как источник текста в OBS.

Локальный URL для интеграции возвращает актуальный JSON выбранной сессии. Он предназначен для программ на том же компьютере. Временные отметки в JSON — Unix-время в секундах, длительность — число секунд.
