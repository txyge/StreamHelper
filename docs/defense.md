# Как реализован таймкод

1. **Ожидаемый результат.** Стример начинает эфир, ждёт несколько секунд и ставит подписанную отметку. В списке появляется время от старта сессии, подпись и при наличии приватная заметка. После перезагрузки отметка сохраняется.
2. **Панель.** Форма `mark` в [index.html](../web/index.html) передаёт поля `label` и `note` через обработчик в [app.js](../web/app.js) на `POST /api/sessions/{id}/marks`. Браузер передаёт выбранный ID сессии в URL.
3. **Вычисление.** [Сервер](../app.py) вызывает `streams.mark` внутри транзакции. Метод проверяет наличие активной сессии. [Модуль сессий](../streams.py) вычисляет `max(0, int(текущее серверное время − started))`. Позиция видеоплеера используется только при экспорте клипа.
4. **Хранение и отображение.** В [таблицу marks](../schema.sql) сохраняются ID сессии, секунды, подпись и заметка. После запроса и после обновления страницы панель читает `GET /api/sessions/{id}` и форматирует секунды как ЧЧ:ММ:СС.
5. **Проверка.** В Edge из чистой базы создан эфир, через одну секунду или больше добавлена отметка, затем страница обновлена. Интерфейс снова показал подпись, API вернул сохранённые секунды. По завершении эфира та же отметка появилась в личном итоге. Сценарий повторён для финальной версии [приёмочным тестом](../tests/acceptance.cjs).
