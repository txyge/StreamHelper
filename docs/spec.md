# ТЗ · Режим Twitch

**Цель.** Автоматически собирать вопросы и итоги прямых эфиров собственного канала Twitch. Панель локальная. Зрительский экран открывается во второй вкладке или в OBS Browser Source.

| ID | Требование | Приёмка |
|---|---|---|
| T01 | Подключить аккаунт Twitch через OAuth Device Code | Стример подтверждает доступ на сайте Twitch. Панель получает имя канала. Токены хранятся локально. |
| T02 | Автоматическая сессия | Старт, название, наблюдаемые категории и конец берутся из Twitch. Повтор событий и опросов не создаёт дубликатов сессии. |
| T03 | Вопросы из реального чата | `!вопрос текст` автоматически добавляет вопрос в правильный эфир. Статус можно изменить из панели. |
| T04 | Аудитория и активность | В итогах видны обнаруженные участники чата и до десяти первых по числу полученных сообщений. |
| T05 | Поддержка и модераторы | Видны лидеры по Bits за эфир, рейтинг Bits на день Twitch и список назначенных модераторов. |
| T06 | Кнопка клипа | Для выбранного эфира запросить новый клип Twitch с указанными границами в его архиве и добавить ссылку после готовности. Подтверждённые клипы связанного VOD также входят в список. |
| T07 | Зрительские итоги | После завершения опубликовать сформированную карточку с длительностью, темой, чат-активностью, Bits, модераторами и клипами. Вторая вкладка получает только опубликованную карточку. |
| T08 | Демонстрация | Локальный экспорт MP4 доступен для демонстрационной сессии без Twitch. Экспорт берёт выбранное число секунд перед позицией плеера и запускается кнопкой или назначенной клавишей во вкладке панели. |
| T09 | Перенесено | Антиспойлер, автомодерация Twitch и сторонние денежные донаты. |

Список аудитории соответствует участникам чата, которых удалось обнаружить во время подключения. Рейтинг за эфир использует события Bits, полученные приложением. В отсутствие связанного VOD список клипов ограничен клипами, созданными из панели. История локального учебного прототипа сохранена в Git и первоначальном отчёте.
