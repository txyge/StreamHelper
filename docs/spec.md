# ТЗ · Локальные итоги трансляции

- Сессия автоматически открывается и завершается по событиям Streamer.bot. Доступно ручное управление.
- Таймкоды привязаны к сессии и вычисляются от её начала.
- Сообщения Twitch с командой `!вопрос` идут через Streamer.bot в отдельную очередь с отметкой об ответе.
- В панели один итог выбранной сессии. Показываются длительность, название, наблюдённые категории и смены темы, обнаруженные зрители, модераторы, замеченные в сессии, и денежные донаты из DonationAlerts за этот интервал.
- Итог доступен для скачивания в JSON и TXT, а также по локальному URL. Настройки DonationAlerts и инструкция подключения открываются из панели.
- Записи сохраняются в локальной SQLite. Публичный экран итогов, публикация и создание клипов удалены из рабочего приложения.
