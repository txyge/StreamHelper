# Приёмка режима Twitch

| Требование | Результат |
|---|---|
| T01 Авторизация | Реализован OAuth Device Code с сохранением и обновлением токена. Проверка с реальным аккаунтом требует Client ID и подтверждения владельца канала. |
| T02 Сессия | Тест проверил автоматическое создание из Twitch-ответа, обновление категорий, закрытие по событию и защиту от повторного открытия устаревшим ответом. |
| T03 Вопросы | Повтор события не создаёт дубль. В Edge вопрос появился в очереди, получил статус «Отвечен». Демонстрационная форма была скрыта в сессии Twitch. |
| T04 Аудитория | Проверены несколько страниц списка участников и ранжирование по сообщениям. |
| T05 Поддержка и модераторы | Проверены отдельные суммы за эфир и день из тестовых данных Twitch, а также получение списка модераторов. |
| T06 Клип | На тестовом ответе проверен POST создания нового клипа из архива с концом на 45-й секунде и длительностью 30 секунд. Проверены отказы при недоступном архиве и неверных границах, получение ссылки и исключение клипа из другого VOD. Создание клипа в реальном эфире требует авторизации владельца. |
| T07 Итоги | В Edge вторая вкладка получила опубликованные категории, длительность, активность, Bits и ссылку на клип. Личный вопрос остался в панели. SQLite сохранила снимок независимо от поздних событий. |
| T08 Демонстрация | В Edge проверены отсутствие тестового чата и экспорт локального MP4 назначенной клавишей. FFprobe подтвердил выбранную длительность 17 секунд. Проверены сохранение клавиши после обновления и сброс. |
| T09 Отложено | Антиспойлер и автомодерация убраны из рабочей панели. Внешние донаты требуют источника данных. |

Тесты Twitch используют воспроизводимые ответы Helix и события EventSub. Для повторения из папки проекта:

```powershell
py -3 -m unittest tests.test_twitch -v
npm.cmd install --no-save --no-package-lock playwright
node .\tests\acceptance.cjs
```

Для браузерного теста нужны Edge и FFmpeg/FFprobe. Если команды недоступны через PATH, задайте `STREAMHELPER_PYTHON`, `STREAMHELPER_FFMPEG` и `STREAMHELPER_FFPROBE`.
