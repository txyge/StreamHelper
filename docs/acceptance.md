# Приёмка СтримПомощника

**Среда.** Windows, Python 3.12.14, SQLite из стандартной библиотеки, Edge 158.0.4370.33 в headless-режиме через Playwright, FFmpeg и FFprobe 7.0.2. Проверка 24 ноября 2026 года. Первый сервер запущен с новым каталогом данных и встроенной записью 55 секунд. Первый ответ списка сессий был `[]`, публичный API вернул `null`. Участие Twitch, OBS и ручное редактирование базы для прогона не потребовались.

## Матрица требований

| Требование | Статус | Как проверить |
|---|---|---|
| F01 Сессия | реализовано | Начать и завершить эфир. Проверить обе даты и HTTP 409 при повторном завершении. |
| F02 Таймкод | реализовано | Через несколько секунд сохранить подпись и заметку, обновить страницу. Сверить секунды с API. |
| F03 Кнопка клипа | реализовано | Загрузить деморолик и нарезать с позиций 45 и 12. Открыть и скачать оба файла. Проверить ошибки на позиции 0 и без записи. |
| F04 Голос | частично | Включить голос в Edge. Проверка headless показала отказ доступа к микрофону и подсказку. Распознавание произнесённой команды требует проверки в обычном браузере с разрешённым микрофоном и доступным сервисом распознавания. |
| F05 Вопросы | реализовано | Отправить `!вопрос Когда следующий эфир?`, отметить отвеченным и обновить страницу. |
| F06 Антиспойлер | реализовано | Добавить фразу «тайный финал» и отправить её в верхнем регистре, затем как часть вопроса. Восстановить вопрос и проверить очередь. |
| F07 Личные итоги | реализовано | После завершения просмотреть длительность, отметки, два клипа, вопросы и счётчик. Перезапустить сервер на той же базе. |
| F08 Итоги зрителям | реализовано | Выбрать элементы, проверить предпросмотр, опубликовать. В уже открытой вкладке появится карточка. |
| F09 Снимок публикации | реализовано | Сравнить ответ `GET /api/viewer` с опубликованными полями. Изменить черновик, не публикуя его. |
| F10 Демонстрация без Twitch | реализовано | Запустить на Windows и пройти сценарий со встроенными видео и чатом. |
| F11 Захват эфира | перенесено | Вне сценария с локальной записью. Следующий шаг — проверить локальный захват через OBS Replay Buffer. |
| F11 Фоновый голос | перенесено | Текущая версия распознаёт речь по кнопке вкладки. Следующий шаг — прототип локального распознавания с явным переключателем. |
| F11 Публикация в Twitch | перенесено | Демонстрация автономна. Следующий шаг — выбрать официальный способ публикации и проверить с тестовым аккаунтом. |

## Сквозной прогон

| Шаг | Ожидалось | Наблюдалось |
|---|---|---|
| Открыть панель и зрительскую страницу | Пустая база, публиковать пока нечего | Панель загрузилась, список `[]`, экран «Итоги ещё не опубликованы», JSON `null`. |
| Начать эфир, выждать паузу, сохранить «Победа» с заметкой и обновить панель | Отметка восстанавливается. Одновременно активен один эфир | Отметка сохранилась, в последнем прогоне её отсчёт составил 3 с. Вторая активная сессия и публикация до завершения получили 409. |
| Отправить обычное сообщение, вопрос и два спойлера | Обычное сообщение видно, вопрос со спойлером задержан | В ленте видны обычное сообщение и открытый вопрос. Правило «Тайный финал» сработало в разном регистре. После восстановления в очереди появился второй вопрос. Статус первого пережил обновление. |
| Нажать кнопку без записи и в позиции 0 | Понятные ошибки, без файла | Панель показала «Сначала загрузите запись» и «Пустой отрезок». Сервер отклонил оба запроса со статусом 400. |
| Экспортировать с позиции 45, затем 12 | Интервалы [15, 45] и [0, 12]. Оба файла доступны | FFprobe измерил ровно 30 и 12 секунд. FFmpeg полностью декодировал оба скачанных MP4 без ошибок. Edge открыл оба клипа и прочитал их длительности. |
| Завершить эфир, прочитать личные итоги | Длительность зафиксирована. Итог содержит таймкод, клипы, вопросы и модерацию | Длительность совпала с разностью времён. Два клипа, два вопроса, два срабатывания правил, одно сообщение всё ещё скрыто. Повторное завершение вернуло 409 и сохранило прежнее время. |
| Выбрать момент, вопрос и результат «3 из 3», опубликовать | Предпросмотр появляется до публикации. Вторая вкладка обновится сама | До публикации публичный JSON был `null`. После публикации открытая вкладка показала «3 из 3» без ручного обновления. Сетевые запросы вкладки к API обращались только к `/api/viewer`. |
| Сравнить публичную карточку и изменить черновик | Публичный снимок содержит только выбранные поля и сохраняется | Точное сравнение обнаружило ключи `duration`, `moment{seconds,label}`, `question{nick,body}`, `challenge`. Приватная заметка, скрытое сообщение, невыбранный вопрос и пустой анонс отсутствовали. Редактирование результата и анонса появилось в предпросмотре. Снимок API и вторая вкладка сохранили прежние значения. |
| Начать второй эфир, перезапустить сервер | Данные сессий изолированы, первый итог и публикация сохранены | Чужие вопрос и запись отклонены. После перезапуска совпали JSON личного итога и публикации. Переключение на первый эфир в панели вернуло два клипа. Запрос первых 32 байтов клипа вернул 206 и 32 байта. |
| Повторить экспорт с неверно настроенным кодировщиком | Интерфейс сообщает об ошибке, неполный клип не попадает в хранилище | Повторный запуск с путём FFprobe вместо FFmpeg вызвал отображаемую ошибку экспорта. Остались две записи и два готовых файла. |

Кнопка «Включить голос» отдельно проверялась в Edge headless. Появилось сообщение «Разрешите браузеру доступ к микрофону». Живой микрофон, распознавание произнесённой команды и вставка в OBS не проверялись. Страница зрителей проверена как отдельная вкладка браузера.

## Повторить тест

[Ручной сценарий](../README.md) покрывает основную цепочку. [Автоматическая проверка](../tests/acceptance.cjs) использует Node.js 20+, пакет Playwright, установленный Edge и временный каталог. Команды запускаются из папки проекта. Для работы самого приложения эти тестовые зависимости не нужны.

```powershell
npm.cmd install --no-save --no-package-lock playwright
node .\tests\acceptance.cjs
```

Если команды Python, FFmpeg и FFprobe недоступны через PATH, сначала задайте переменные из [README](../README.md). Для теста также можно указать `STREAMHELPER_EDGE` с путём к Edge и `STREAMHELPER_TEST_ROOT` с доступным для записи каталогом. Код теста выводит результат по каждому этапу и завершается с ненулевым кодом при ошибке.
