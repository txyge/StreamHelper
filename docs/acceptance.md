# Проверка локальных итогов

- Тесты Python воспроизводят события Twitch по схеме Streamer.bot. Проверены подписка, автоматические границы эфира, дедупликация вопросов, смена категории, фиксация модератора по значку и действию, обнаружение зрителя и постановка таймкода.
- Тест DonationAlerts проверяет OAuth на тестовом ответе и получение двух страниц истории. В итог попадают платежи только между началом и концом сессии, повторы платежей не дублируются.
- В Edge проверены интерфейс таймкодов, очередь со статусом ответа, единый итог и отсутствие маршрутов клипов, публикации и экрана зрителей.
- В Edge проверены скачивание JSON и TXT, локальный URL итога, инструкция и сохранение настроек DonationAlerts из панели. Тест Python проверяет восстановление настроек и авторизации после перезапуска, а также сброс авторизации при смене реквизитов приложения.
- Для проверки с реальными данными требуется подключить аккаунты к Streamer.bot и DonationAlerts. См. [инструкцию запуска](../README.md).

```powershell
py -3 -m unittest tests.test_twitch -v
npm.cmd install --no-save --no-package-lock playwright
node .\tests\acceptance.cjs
```
